## 1. 用户提出的问题

| 问题 | 结论 |
| --- | --- |
| 「上传用途」无意义 | 去掉选择，改为按类型分类筛选 |
| 头像归到哪个文件夹 | 头像走独立入口，存 `avatar` 来源，页面可上传 |
| 上传人显示 `—` | 后端已返回 `uploaded_by_name`，前端取错字段 |
| 图片不能预览 | 列表显示缩略图，点击放大 |
| 复制链接 vs 下载有何区别 | 复制 = 可分享地址（公开桶为永久直链），下载 = 本次保存文件 |
| 签名 token 无意义 | 公开模式不再带 token，改由配额防滥用 |

## 2. 文件管理页改版

### 2.1 顶部

```
[上传文件]  拖拽或点击，≤20MB
分类 [全部▾]  关键字 [____]  [查询]

已用 128 MB / 1024 MB   ▓▓▓▓░░░░░░
```

- 配额进度条来自 `GET /admin/files/usage`
- 超过 90% 变橙色，上传失败时显示后端 message

### 2.2 列表

| 列     | 内容                                           |
| ------ | ---------------------------------------------- |
| 预览   | 图片显示缩略图（48×48 圆角），其他显示类型图标 |
| 文件名 | 原文件名                                       |
| 分类   | 图片 / 文档 / 表格 / 压缩包 / 文本             |
| 大小   | KB/MB                                          |
| 上传人 | `uploaded_by_name`，为空回退 `#id`             |
| 时间   | 本地时间                                       |
| 操作   | **预览**（仅图片）/ 下载 / 复制链接 / 删除     |

- 点击缩略图或「预览」打开大图弹窗（原图，带文件名与大小）
- 「复制链接」提示：公开模式「长期有效」，私有模式「5 分钟内有效」
- 不再显示「用途」列

### 2.3 上传弹窗

```
拖拽文件到此处
可选：备注（不参与分类）
```

- 去掉「上传用途」下拉
- 上传后如果后端返回 `category`，列表筛选自动切到该分类（可选）

## 3. 个人资料头像上传

`/profile` 基本信息卡：

```
头像  [圆形预览]  [上传新头像]  [删除]
      支持 JPG/PNG/GIF，≤2MB
```

- 选择文件后立即上传，成功即更新预览与全局头像
- 失败提示原因（非图片、超过 2MB）
- 「删除」恢复默认头像（后端置空）
