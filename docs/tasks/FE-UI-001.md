## 2. A · 登录企业代码

### 接口（后端 BE-IDN-001 交付）

```jsonc
POST /auth/login
{ "tenant": "acme", "account": "admin", "password": "..." }
```

- `tenant` 为租户 code；缺省时后端用 `tenant.default_code`
- 失败文案统一：「企业代码、账号或密码错误」

### 改动

| # | 改动 |
| --- | --- |
| 1 | 登录页新增「企业代码」输入框，默认填 `VITE_DEFAULT_TENANT_CODE`（缺省 `default`） |
| 2 | 记住上次输入的企业代码（localStorage 只存 code） |
| 3 | 移除 `VITE_PLATFORM_TENANT_ID` 的隐式传参 |
| 4 | 登录失败统一提示，不区分租户不存在/密码错误 |
| 5 | 登录成功后顶栏显示当前租户 code（来自 `/auth/me.tenant_code`） |

## 3. B · 个人资料

### 接口

```
GET /auth/me           当前用户（用户名/昵称/邮箱/手机/头像/部门/角色/tenant_code）
PUT /auth/profile      修改昵称/邮箱/头像
PUT /auth/password     改密（旧密码 + 新密码）
```

### 页面

`/profile`（或系统菜单外独立入口，头像下拉）

**基本信息**

| 字段               | 可改                                             |
| ------------------ | ------------------------------------------------ |
| 用户名             | 否                                               |
| 昵称               | 是                                               |
| 邮箱               | 是（保存后提示「下次登录生效」按后端实际语义写） |
| 手机               | 是                                               |
| 头像               | 是（先用 URL 输入，上传留到文件模块完成后）      |
| 部门 / 角色 / 租户 | 否，只读展示                                     |

**修改密码**

独立卡片：旧密码、新密码、确认新密码。

- 前端校验：长度 ≥ 8、含字母与数字（与后端策略一致）
- 成功后提示「其他设备的登录已失效」（后端会撤销其他会话）
- 失败显示后端原文

## 4. C · 我的会话

### 接口

```
GET  /auth/sessions        我的会话列表
POST /auth/logout-all      全部下线
```

### 页面

`/profile/sessions`（或在资料页内的页签）

| 列         | 说明           |
| ---------- | -------------- |
| 登录时间   | created_at     |
| IP         |                |
| User-Agent | 截断 + tooltip |
| 状态       | 当前/其他      |

操作：「全部下线」二次确认，成功后回登录页。

## 5. D · 登出、首页与 404

### D1 登出

现状：清 token 但不跳转，表单仍在原页。

```
登出 → 清空 auth store 与 sessionStorage
     → location.replace('/auth/login')   （replace 防止后退回到内页）
```

无论后端登出接口成功与否，本地状态必须清干净。

### D2 真实首页

现状：登录后进入 `/home`，它自动重定向到「用户拥有的第一个菜单」。无权限用户 → 404。

改为**真实首页**：

```
顶部：欢迎语 + 当前租户 + 今日日期
中部：快捷入口（按权限过滤，最多 6 个）
      无任何权限时显示：「你还没有被分配权限，请联系管理员」
底部：最近通知（3 条，无权限则隐藏）
```

首页**不做数据聚合接口**（避免为它新增后端 API），只做静态 + 已有接口。

### D3 404

- 路由未匹配 → `/_core/fallback/not-found.vue`
- 无权限访问已知路由 → 403 页（已有则复用）
- 404 页要有「返回首页」与「返回上一页」

## 6. 验收

| # | 项 | 断言 |
| --- | --- | --- |
| 1 | 企业代码登录 | 用 `default` 登录成功；用另一租户 code 登录成功并进入其菜单 |
| 2 | 记住代码 | 关闭浏览器再打开，企业代码保留，密码不保留 |
| 3 | 错误文案 | 错误租户 code 与错误密码显示同一文案 |
| 4 | 顶栏租户 | 登录后显示当前租户 code |
| 5 | 资料展示 | 昵称/邮箱/手机/部门/角色/租户正确 |
| 6 | 资料修改 | 改昵称保存后刷新仍生效 |
| 7 | 改密 | 旧密码错误被拒；成功后其他会话失效、当前会话保留 |
| 8 | 密码规则 | 8 位以下、纯字母被前端拦截 |
| 9 | 会话列表 | 显示多台设备；「全部下线」后回登录页 |
| 10 | 登出 | 点登出后回到登录页，后退无法回到内页 |
| 11 | 首页 | 有权限用户看到快捷入口；无权限用户看到空态提示而非 404 |
| 12 | 404 | 访问不存在路径显示 404 页，可返回首页 |
| 13 | 构建 | lint / typecheck / unit / build 全绿 |

## 7. 不做

- 头像上传（依赖文件管理模块）
- 邮箱变更的二次验证（P2）
- 首页数据图表（需要后端聚合接口）
- 企业代码输入的历史下拉（泄露租户列表）
