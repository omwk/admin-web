# SF-1 · 部门管理页

- 依赖：后端 S1（部门 CRUD）、FE-1.5（既有页面模式）
- 预计：**1.5 人日**
- 分支：`feat/sf-1-dept`
- 完成标志：在界面上完成部门的增删改与层级调整，无需 SQL

---

## 1. 接口

| 接口                       | 用途               |
| -------------------------- | ------------------ |
| `GET /admin/depts`         | 部门树（含成员数） |
| `GET /admin/depts/{id}`    | 详情               |
| `POST /admin/depts`        | 新建               |
| `PUT /admin/depts/{id}`    | 更新（含移动父级） |
| `DELETE /admin/depts/{id}` | 删除               |

## 2. 页面

### 2.1 布局

左侧部门树 + 右侧详情/表单（沿用 FE-1.5 的左右布局习惯）。

- 树节点显示：名称、成员数徽标、状态
- 树操作：行内「新增子部门」「编辑」「删除」
- 顶部：搜索框（按名称过滤，保留树形结构）、「新增根部门」

### 2.2 表单

| 字段     | 控件                         | 校验                   |
| -------- | ---------------------------- | ---------------------- |
| 上级部门 | 树选择器（可为「无（根）」） | 不能选自己或自己的后代 |
| 名称     | 输入                         | 必填，1–64 字          |
| 排序     | 数字                         | 默认 0                 |
| 状态     | 启用/停用                    |                        |

**上级选择器必须禁用当前节点及其所有后代**——这是前端能提前拦住「成环」的唯一位置。

### 2.3 删除

删除前二次确认，并说明后果：

```
删除「电商事业部」后不可恢复。
若该部门下有子部门或在册用户，后端会拒绝删除。
```

后端返回 409 时，把 message 原样展示（不要只显示「操作失败」）。

## 3. 关键要求

### 3.1 移动部门后的刷新

移动父级后必须重新拉取整棵树，不能只更新本地节点——`path` 与后代层级都会变。

### 3.2 空态

- 无部门：显示「暂无部门，先创建一个」
- 无搜索结果：显示「没有匹配的部门」

### 3.3 权限

- 无 `system:dept:create` → 隐藏新增按钮
- 无 `system:dept:update` → 隐藏编辑
- 无 `system:dept:delete` → 隐藏删除
- 直接调接口仍由后端 403 兜底

## 4. 验收

| #   | 项       | 断言                                                 |
| --- | -------- | ---------------------------------------------------- |
| 1   | 树渲染   | 真实数据 8 个部门按层级显示，成员数正确              |
| 2   | 新建     | 建一级与二级部门后，树即时出现且 path 顺序正确       |
| 3   | 改名     | 改名后树与详情同步                                   |
| 4   | 移动     | 把带子部门的节点移到另一父级，刷新后整个子树层级正确 |
| 5   | 防环     | 上级选择器中看不到自己与后代                         |
| 6   | 重名     | 同父重名提交 → 显示后端 400 文案                     |
| 7   | 删除保护 | 删有子部门的节点 → 显示 409 文案                     |
| 8   | 删除成功 | 空部门删除后从树中消失                               |
| 9   | 权限     | 无权限账号看不到对应按钮；直连接口 403               |
| 10  | 构建     | lint / typecheck / unit / build 全绿                 |

## 5. 不做

- 拖动排序（用表单里的 sort 字段）
- 批量移动
- 部门成员列表页
