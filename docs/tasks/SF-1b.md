# SF-1b · 去掉「新增根部门」

- 类型：前端修正（S1c 的配套）
- 预计：**0.2 人日**
- 分支：`fix/sf-1b-root`

---

## 1. 背景

后端 S1c 已收敛根部门语义：

```
根部门唯一（seed 创建，path=1）
POST parent_id=0 → 400「已存在根部门，请选择上级部门」
PUT  parent_id=0 → 400「根部门不可移动」
```

前端 SF-1 仍有「新增根部门」按钮，点一次就产生一次失败请求。

## 2. 改动

| #   | 改动                                                               |
| --- | ------------------------------------------------------------------ |
| 1   | 去掉「新增根部门」按钮                                             |
| 2   | 改为「新增一级部门」，父级固定为根部门                             |
| 3   | 表单里「上级部门」字段在一级部门时隐藏（值固定为根）               |
| 4   | 若后端仍返回「已存在根部门」（例如根被删的异常数据），原样展示文案 |

## 3. 验收

| #   | 项       | 断言                                               |
| --- | -------- | -------------------------------------------------- |
| 1   | 按钮     | 工具栏只有「新增一级部门」与「新增子部门」         |
| 2   | 一级部门 | 新建后 parent_id = 根部门 id，树中出现在根下第一层 |
| 3   | 子部门   | 行内「新增子部门」仍以该行为父                     |
| 4   | 表单     | 一级部门表单不显示「上级部门」                     |
| 5   | 构建     | lint / typecheck / unit / build 全绿               |

## 4. 不做

- 根部门改名、排序（SF-1 已支持）
- 部门拖动
