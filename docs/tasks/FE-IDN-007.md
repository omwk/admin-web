## 1. 为什么要有这个页面

当前模板只能「从租户克隆、改名字」，实际上只能有默认模板一个。
建好模板后无法调整角色与权限，等于没有「多套租户方案」的能力。

## 2. 接口

```
GET    /admin/tenant-templates
POST   /admin/tenant-templates               { code, name, description, source_tenant_id? }
GET    /admin/tenant-templates/{id}          → { roles, menus, ... }
PUT    /admin/tenant-templates/{id}          { name, description, roles }
DELETE /admin/tenant-templates/{id}
POST   /admin/tenant-templates/{id}/clone    { code, name }
```

## 3. 页面

### 3.1 模板列表（`/system/tenants/templates`）

| 列          | 内容                             |
| ----------- | -------------------------------- |
| 名称 / 代码 |                                  |
| 角色数      | `2 个`                           |
| 权限数      | 去重后的权限码数量               |
| 使用中      | 引用该模板的租户数               |
| 创建时间    |                                  |
| 操作        | 编辑 / 复制 / 删除（被引用禁用） |

顶部操作：

```
[从租户创建]  → 选择租户 + code + name（快照）
[新建空白模板] → code + name + description
```

### 3.2 模板编辑页

左右布局：

```
左侧：角色列表              右侧：选中角色的权限配置
┌──────────────┐   ┌────────────────────────────────┐
│ 运营  (2 权限) │   │ 角色名 [运营]     数据范围 [本人▾] │
│ 只读  (1 权限) │   │ 权限：按模块分组的勾选树          │
│ [+ 添加角色]   │   │  交易 (2/15)                   │
└──────────────┘   │   ☑ 订单列表  ☑ 订单详情        │
                   │  ...                           │
                   │ 已选菜单：只读展示（来自模板）     │
                   └────────────────────────────────┘
```

要求：

- 角色可增删；角色名、数据范围可改；角色 code 创建后不可改
- 权限勾选复用角色页的分组组件（按 module 折叠、搜索、整组勾选）
- 菜单只读展示（模板的菜单树由框架决定，不允许编辑）
- 未保存时离开页面要提示
- 保存前校验：角色名为空、权限为空（允许但提示）、角色 code 重复

### 3.3 开通向导的空态

模板列表为空时，第二步应显示：

```
还没有可用的租户模板
[去创建模板]（跳到模板页）
```

而不是一个空下拉。

若选中的模板角色数为 0，显示警告：

```
该模板不含角色，开通后除管理员外没有其他角色可用。
```

## 4. 验收

| #   | 项         | 断言                                           |
| --- | ---------- | ---------------------------------------------- |
| 1   | 列表       | 显示角色数、权限数、使用中数量                 |
| 2   | 空白创建   | 建出 roles 为空的模板并进入编辑页              |
| 3   | 添加角色   | 新增「只读」角色并勾选 1 个权限，保存成功      |
| 4   | 权限分组   | 权限按模块折叠，支持搜索与整组勾选             |
| 5   | 数据范围   | 五种范围可切换                                 |
| 6   | 回填       | 刷新后角色与权限与保存时一致                   |
| 7   | 复制       | 复制模板后修改副本不影响原模板                 |
| 8   | 打开通验证 | 用「只读版」模板开通租户，该租户角色与权限正确 |
| 9   | 空态       | 无模板时向导显示空态与跳转按钮，不是空下拉     |
| 10  | 零角色警告 | 选择无角色模板时显示警告但仍可开通             |
| 11  | 未保存提示 | 修改后离开页面弹出确认                         |
| 12  | 构建       | lint / typecheck / unit / build 全绿           |
