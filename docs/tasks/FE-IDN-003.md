## 1. 背景

会话页当前只有「全部下线」，而它会把**当前设备也踢掉**。
缺一个「保留当前、下线其他」的动作。

## 2. 改动

会话页（FE-UI-001 已建）增加：

| 位置 | 改动 |
| --- | --- |
| 顶部按钮 | 「全部下线」旁增加「下线其他设备」 |
| 行操作 | `current=false` 的行显示「下线」；`current=true` 的行显示「当前设备」不可下线 |

「下线其他设备」：

- 二次确认：「将下线除当前设备外的 2 个会话，确定？」
- 成功后列表刷新，只剩当前一条，并提示「已下线 2 个会话」

## 3. 验收

| #   | 项       | 断言                                             |
| --- | -------- | ------------------------------------------------ |
| 1   | 按钮     | 顶部有「下线其他设备」，仅当我存在多条会话时可用 |
| 2   | 行操作   | 当前设备行无下线按钮，显示「当前设备」标记       |
| 3   | 单条下线 | 点击其他行的「下线」→ 该行消失，当前会话仍可用   |
| 4   | 下线其他 | 确认后只剩当前一条，提示数量正确                 |
| 5   | 幂等     | 仅剩一条时按钮禁用                               |
| 6   | 全部下线 | 保持原有行为：回登录页                           |
| 7   | 构建     | lint / typecheck / unit / build 全绿             |
