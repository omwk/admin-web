# SF-3 · 审计日志、登录历史与用户解锁

- 依赖：后端 S4（审计查询、登录历史、解锁，已合并）
- 预计：**2 人日**
- 分支：`feat/sf-3-audit`
- 完成标志：能在界面上查审计、看登录历史、解锁被锁账号

---

## 1. 为什么单独一张卡

S4 交付了三个后端接口，但**前端页面从未规划**——SF-2 只做了通知。
结果是：管理员能通过 SQL 查审计，界面上却看不到。

## 2. 接口

| 接口 | 用途 |
| --- | --- |
| `GET /admin/audit-logs?actor_id=&action=&resource_type=&result=&from=&to=&page=&page_size=` | 审计查询 |
| `GET /admin/login-logs?user_id=&result=&from=&to=&page=&page_size=` | 登录历史 |
| `POST /admin/users/{id}/unlock` | 解锁 |

权限：`system:audit:list`、`system:user:update`。

## 3. 页面

### 3.1 审计日志 `/system/audit-logs`

- 筛选条：操作类型（action）、资源类型、结果（成功/失败）、操作者、时间范围
- 表格列：时间、操作者、动作、资源、结果、IP
- 行展开：`before` / `after` 的差异视图（JSON 树，敏感值已由后端替换为 `***`）
- 超过 4KB 的记录显示「内容已截断」标记
- 只读，无任何写操作入口

### 3.2 登录历史 `/system/login-logs`

- 筛选：用户、结果、时间范围
- 表格列：时间、用户（未知账号显示「未知账号」）、结果、IP、User-Agent
- 未知账号行不得显示任何可能的账号输入
- User-Agent 过长时截断显示 + tooltip 全文

### 3.3 用户页的解锁

在用户管理页的行操作里，对 `status=locked` 的用户显示「解锁」：

- 二次确认：「解锁后该用户可立即尝试登录」
- 成功后状态列即时变为 `active`
- 对 `disabled` 用户不显示解锁按钮（后端会 409）

## 4. 关键要求

### 4.1 只读语义

审计与登录历史页面**不得**出现删除、编辑、导出按钮。这两张表是证据链，任何修改都会破坏它的价值。

### 4.2 时间与分页

- 时间统一按本地时区展示，筛选器提交 RFC3339
- 分页沿用既有组件；跨页筛选条件保持

### 4.3 空态

| 场景       | 文案                       |
| ---------- | -------------------------- |
| 无审计     | 「当前筛选条件下没有记录」 |
| 无登录历史 | 「暂无登录记录」           |
| 筛选过窄   | 提供「清空筛选」按钮       |

## 5. 验收

| #   | 项       | 断言                                               |
| --- | -------- | -------------------------------------------------- |
| 1   | 审计列表 | 真实数据 ≥5 行，倒序，列齐全                       |
| 2   | 审计筛选 | action / result / 时间范围单独与组合过滤生效       |
| 3   | 差异视图 | before/after 以树展示；敏感值为 `***`              |
| 4   | 截断标记 | 超 4KB 记录显示「内容已截断」                      |
| 5   | 登录历史 | 成功与失败记录都在，IP/UA 显示正确                 |
| 6   | 未知账号 | 显示「未知账号」，页面与网络响应无输入的账号串     |
| 7   | 解锁     | 锁定用户点击解锁 → 状态变 active；随后该用户可登录 |
| 8   | 解锁保护 | disabled 用户无解锁按钮；直调接口 409 有提示       |
| 9   | 只读     | 两页均无写操作按钮                                 |
| 10  | 权限     | 无 `system:audit:list` 时菜单隐藏且直连 403        |
| 11  | 构建     | lint / typecheck / unit / build 全绿               |
