## 1. 现象

开通租户第二步，管理员邮箱填 `47wmdyhhd` 后点「确认开通」：

```
┌ 开通租户 ────────────────────────┐
│ ✔ 基本信息 ──────── ② 模板与管理员 │
│ ⓧ 请填写有效的管理员邮箱（最多 256 字符），或留空  │
│ 租户模板 [base (3 个角色) ▾]        │
│ 管理员用户名 [admin]                │
│ 管理员邮箱（可选）[47wmdyhhd]       │
└──────────────────────────────┘
```

### 判定：校验正确，提示方式差

代码（`provision-wizard.vue:75`）：

```ts
const email = form.admin_email.trim();
if (
  email &&
  (email.length > 256 || !/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email))
) {
  error.value = '请填写有效的管理员邮箱（最多 256 字符），或留空';
  return;
}
```

- **可选 ≠ 不校验**：留空合法；填了就必须是合法邮箱
- `47wmdyhhd` 不是邮箱，阻止提交是对的

问题在于**呈现**：

| 问题                              | 影响                            |
| --------------------------------- | ------------------------------- |
| 错误显示在顶部横幅，离字段 4 行远 | 看起来像整页失败，不像字段错误  |
| 只有提交时才校验                  | 用户填完不知道要改              |
| 输入框无占位示例                  | 不知道期望格式是 `ops@acme.com` |
| 输入框无错误态（红框）            | 无法定位是哪个字段              |

## 2. 改动

### 2.1 字段级错误

改为表单字段错误（沿用项目已有的表单校验方式）：

- 错误文案显示在**输入框下方**
- 输入框红色边框
- 顶部横幅只保留**服务端错误**（如 409 租户代码重复）

### 2.2 校验时机

| 时机     | 行为                                 |
| -------- | ------------------------------------ |
| blur     | 校验该字段（空值不报错）             |
| 输入变化 | 若该字段已有错误，实时重新校验以清除 |
| 提交     | 校验全部字段，聚焦第一个错误         |

### 2.3 占位与说明

```
管理员邮箱（可选）  [例如 ops@acme.com]
填了就必须是合法邮箱；留空也可以，管理员可用邀请链接自行设置。
```

### 2.4 同类字段一并处理

同一表单的「租户代码」「租户名称」「管理员用户名」目前也是提交时顶部横幅报错，
统一改为字段级。

## 3. 验收

| #   | 项         | 断言                                         |
| --- | ---------- | -------------------------------------------- |
| 1   | 空邮箱     | 留空提交成功，无错误提示                     |
| 2   | 非法邮箱   | 错误显示在字段下方 + 红框，顶部无横幅        |
| 3   | 实时清除   | 改回合法邮箱后错误立即消失                   |
| 4   | 提交聚焦   | 多个字段非法时聚焦第一个错误字段             |
| 5   | 服务端错误 | 租户代码重复仍显示在顶部横幅（不是字段错误） |
| 6   | 占位符     | 邮箱输入框有示例占位与说明文案               |
| 7   | 其他字段   | 代码/名称/用户名同样走字段级校验             |
| 8   | 构建       | lint / typecheck / unit / build 全绿         |

- 表单布局调整
