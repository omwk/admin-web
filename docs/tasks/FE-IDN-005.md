## 1. 背景

审计页当前把 before/after 原样摊开。读操作的两份数据相同，
看起来像"改了什么但看不出改了什么"。

## 2. 改动

### 2.1 差异展示

| 情况                   | 展示                              |
| ---------------------- | --------------------------------- |
| before 与 after 都为空 | 显示「—」                         |
| 只有 after（新建）     | 显示「新建」+ 字段表              |
| 只有 before（删除）    | 显示「删除」+ 字段表              |
| 两者都有且相同         | 显示「无变化」                    |
| 两者不同               | 逐字段对比：旧值删除线 / 新值高亮 |

### 2.2 列与筛选

| 项 | 改动 |
| --- | --- |
| 「操作」列 | action 点号形式显示为中文化名称（映射表见后端 `audit-events.md`） |
| 「目标租户」列 | 跨租户操作显示 target_tenant（来自 after 元数据） |
| 筛选 | 增加「结果」「来源 IP 是否为空」？——先只保留现有筛选 |
| 详情 | 读操作显示「访问范围：12 个租户」而非字段对比 |

### 2.3 来源信息

IP / User-Agent 为空时显示「—」，不要显示空白单元格。

## 3. 验收

| #   | 项        | 断言                                       |
| --- | --------- | ------------------------------------------ |
| 1   | 读操作    | 显示「访问范围：N 个租户」，不显示字段对比 |
| 2   | 更新操作  | 只列出变化字段，旧值带删除线               |
| 3   | 新建/删除 | 分别显示「新建」「删除」与字段表           |
| 4   | 无变化    | 显示「无变化」                             |
| 5   | 空来源    | IP/UA 为空显示「—」                        |
| 6   | 构建      | lint / typecheck / unit / build 全绿       |
