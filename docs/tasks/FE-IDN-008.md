## 1. 接口

| 方法   | 路径                                   | 说明               |
| ------ | -------------------------------------- | ------------------ |
| GET    | `/admin/tenants?include_archived=true` | 列表，默认不含归档 |
| POST   | `/admin/tenants/{id}/archive`          | 归档（软删）       |
| POST   | `/admin/tenants/{id}/restore`          | 恢复               |
| DELETE | `/admin/tenants/{id}?confirm=<code>`   | 彻底删除           |

错误语义（前端必须原样展示）：

| 状态 | 场景                                                            |
| ---- | --------------------------------------------------------------- |
| 409  | 平台租户不可归档/删除；未归档；归档未满宽限期；**仍有业务数据** |
| 400  | 确认码不匹配                                                    |

## 2. 页面改动

### 2.1 状态列

| 状态              | 展示                     |
| ----------------- | ------------------------ |
| `active`          | 绿色「正常」             |
| `suspended`       | 灰色「已停用」           |
| `deleted_at` 非空 | 红色「已归档」+ 归档时间 |

归档标记优先于 status：归档的租户即使 status=suspended 也显示「已归档」。

### 2.2 筛选

顶部加开关「包含已归档」（默认关闭）。

开启后请求带 `include_archived=true`；关闭时恢复默认。

### 2.3 行操作

| 当前状态            | 操作                               |
| ------------------- | ---------------------------------- |
| active              | 停用、**归档**、查看成员、重发邀请 |
| suspended（未归档） | 启用、**归档**、查看成员           |
| 已归档              | **恢复**、**彻底删除**             |

- 平台租户：归档与删除按钮禁用，悬停提示「平台租户不可归档/删除」
- 无 `system:tenant:manage`：所有写操作隐藏

### 2.4 归档确认

```
归档「acme」后：
- 该租户用户立即无法登录
- 租户从列表隐藏（可勾选「包含已归档」查看）
- 数据保留，可随时恢复
```

### 2.5 彻底删除确认（重点）

这是不可逆操作，必须**输入租户 code 才能提交**：

```
┌ 彻底删除租户 ─────────────────────────┐
│ 此操作不可恢复，将删除该租户下的用户、角色、 │
│ 菜单、字典、令牌等全部数据。              │
│                                        │
│ 该租户有 0 条业务数据。                  │
│                                        │
│ 请输入租户代码 acme 以确认：              │
│ [________________]                     │
│                        [取消] [删除]    │
└────────────────────────────────────────┘
```

要求：

- 输入与 code **完全一致**（区分大小写）时「删除」按钮才可点
- 请求带 `?confirm=<code>`（URL 编码）
- 409 时展示后端 message：
  - 「租户仍有业务数据，暂不支持彻底删除」
  - 「归档未满 7 天」
- 成功后列表刷新并提示「租户已删除」

**不要**在确认框里展示统计数字（如「将删除 12 个用户」）——后端没提供删除前预览接口，
编造或估算都会误导。显示「该租户有 N 条业务数据」时也只用后端返回的信息，
拿不到就省略这一行。
